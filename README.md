# Vane & Hartley: Spectral Investigations (test build)

**Play in your browser: https://gary-dandm.github.io/vane-hartley-play/**

An early prototype of a Victorian ghost-investigation game, for testers. Nothing is balanced yet.
Desktop Chrome, Edge or Firefox with a keyboard; play with sound on, headphones if you can.
Click the game once so it takes the keyboard.

London, 1886. Fifteen years after the Veilfall the dead are seen, and they hunt. Two
agents of Vane & Hartley take the case on Wren Street: find what binds the ghost to the
house, and seal it.

## Controls

| Key | |
|---|---|
| WASD / arrows | move |
| Tab | switch warden |
| H | the other warden waits / follows |
| E | use what is in reach (open, read, try a door) |
| E (hold) | on an object: focus on it (Tobias), or listen to it (Edith) |
| X / Space | draw or sheathe the rapier / swing it |
| F (tap) | throw salt: a ring the ghost can't cross for a while |
| F (hold + walk) | pour a line of salt it can't cross until someone walks over it |
| Q | lamps down or up |
| C | the case file (C again turns the page) |
| R | restart |
